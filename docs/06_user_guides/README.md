# Hướng Dẫn Sử Dụng Phần Mềm (User Guides)

Thư mục này chứa toàn bộ các tài liệu hướng dẫn sử dụng dành cho khách hàng doanh nghiệp (Tenant Admin) và nhân viên nghiệp vụ (End-Users).

## Quy Định Bắt Buộc Khi Viết Hướng Dẫn Sử Dụng
1. **Bắt buộc có hình ảnh trực quan (Visual-First Rule)**:
   - Mỗi bước thao tác quan trọng **bắt buộc phải có hình ảnh chụp màn hình (screenshots)** hoặc biểu đồ trực quan minh họa vị trí nút bấm, trường nhập liệu, và kết quả hiển thị.
   - Tuyệt đối nghiêm cấm viết tài liệu chỉ toàn text mà không có hình ảnh.
2. **Lưu trữ hình ảnh**:
   - Tất cả hình ảnh minh họa được lưu tại thư mục con: `assets/<mã_tính_năng>/` (Ví dụ: `assets/sales/create_order_step1.png`).
3. **Mẫu tài liệu chuẩn**:
   - Sử dụng mẫu [TEMPLATE.md](TEMPLATE.md) để soạn thảo.
