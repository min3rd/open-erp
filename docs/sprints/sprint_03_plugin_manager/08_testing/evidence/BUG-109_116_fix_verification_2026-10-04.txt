BUG-115 (Critical) — Toàn bộ nhóm P10–P15, P19–P23 trả 404
----------------------------------------------------------
Root cause: JAX-RS (RESTEasy Reactive) chọn root-resource theo class-level path khớp DÀI NHẤT rồi mới
match method, và KHÔNG fallback về class có path ngắn hơn. Class `PlatformPluginGovernanceResource`
đặt `@Path("/api/v1/platform")` nên mọi method con nằm dưới `/tenants/...` và `/plugins/...` bị
`PlatformTenantResource` (`/api/v1/platform/tenants`) và `PlatformPluginAdminResource`
(`/api/v1/platform/plugins`) che khuất → 404. Chỉ `GET /tenant-private-plugins` hoạt động vì
không có class nào trùng prefix.

Fix (giữ nguyên URL theo DES-03-API):
- `PlatformPluginGovernanceResource` → `@Path("/api/v1/platform/tenant-private-plugins")` (P14/P15).
- Mới `PlatformTenantPluginEntitlementResource` → `@Path("/api/v1/platform/tenants/{tenantId}/plugins")` (P12/P13).
- P10/P11 + P19–P23 chuyển vào `PlatformPluginAdminResource` (owner của `/api/v1/platform/plugins`).

Regression lock: `PlatformPluginGovernanceApiTest` (mới) — 5/5 PASS:
  P12/P13 grant/revoke 200 + ledger NOT_INSTALLED; P10/P11 preview + apply 200; P14 support read 200,
  no-token 401; support write 403; P19–P21 install→disable→enable→uninstall 200.

BUG-116 (High) — Install bundle 500 do docker build trong transaction saga
--------------------------------------------------------------------------
Fix:
- Mới `PluginBundleImageService.ensureBundleImage`: đọc metadata (tx ngắn) → build image NGOÀI JTA
  transaction → cache `distribution.image_ref` (tx ngắn). Idempotent, no-op khi không phải JAR_BUNDLE.
- Pre-flight gọi trước saga tại: `TenantPluginResource.install/upgrade`,
  `PlatformPluginAdminResource.install/upgrade/rollback/applyBulk`.
- Fallback trong `PluginLifecycleService.resolveBundleImage` dùng `QuarkusTransaction.suspendingExisting()`
  để không giữ transaction khi build.

Regression lock: `PluginBundleImageApiTest` (mới) — 3/3 PASS:
  build chạy với `QuarkusTransaction.isActive() == false`; cache image_ref; install dùng cache
  (builder không gọi lại); fallback suspend transaction.
