# Product Backlog (Tồn Đọng Sản Phẩm)

Thư mục này lưu trữ các file yêu cầu (`FEAT-xxx.md`), task kỹ thuật (`TASK-xxx.md`), hoặc ý tưởng refactor (`REFACTOR-xxx.md`) chưa được phân bổ vào bất kỳ Sprint cụ thể nào.

## Quy Trình Xử Lý
1. Khi có yêu cầu mới chưa được đưa vào Sprint hiện tại, tạo file tại đây.
2. Khi bắt đầu Sprint Planning, PM Agent sẽ chọn lọc các item từ thư mục này chuyển vào `sprints/sprint_XX/items/`.
