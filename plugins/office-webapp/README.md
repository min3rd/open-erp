# Office WebApp Plugin (Sprint 12)

Vertical slice của plugin `office-webapp`: đọc/sửa file Office trực tiếp trên trình duyệt, không upload nội dung, không dùng thư viện Office/ZIP/PDF bên thứ ba.

## Đang có

- `web/src/app/core/binary/`: CRC-32, magic bytes, ZIP reader/writer (Store + Deflate), XML parser an toàn, CSV.
- `web/src/app/core/office/`: parser DOCX/XLSX/PPTX/PDF-info, CSV; save DOCX/XLSX/PPTX/CSV; formula engine **410 hàm** + dependency recalc; pivot drag-drop config + chart editing + Table/**native tableParts**/Slicer persisted; **Excel cell styles.xml** + presets/accounting + sort/find/filter/freeze + **insert/delete/autoSum/clear/merge/wrap/indent** + **defined names/protection/comments**; conditional formatting + data validation (create/manage); Word comments/track changes (accept/reject `pPrChange`/`rPrChange` + model sync)/markup/**All-Markup editing**/**undo-redo**/**find-replace**/**insert table-image**/**table structure: insert/delete row-column, header repeat, distribute, cell/table alignment, edit cell text, merge/split cells with `w:gridSpan`/`w:vMerge`**/**run-font formatting**/**paragraph-list-style/page-break**/**clipboard-format painter**/header-footer/notes/citations/TOC/equation/ink/columns-section/accessibility/**embedded image**/**online video**; PPT transition/animation + SmartArt node editing + video/audio playback; PDF annotation layer + text extraction/search.
- `web/src/app/office-webapp.component.*`: shell + workspace + Word/Excel/PPT/PDF viewer, sửa text/ô/shape, nút Lưu, markup All/Simple/No + edit trong All, header/footer + notes + citations + TOC + equation + ink + layout + accessibility panels, ảnh Word inline + link video, pivot field pane + chart editor + CF/DV/Table panels, SmartArt editor + media player, PDF thumbnail sidebar + Ctrl+F search, slideshow PPT, Comments/Track Changes, ERP open/save + Share.
- `web/scripts/smoke.mts`: 394 ca kiểm thử lõi (gồm round-trip tài liệu thầu thực 1.2MB) + round-trip sửa/lưu + formula 410 hàm/pivot/chart/CF/DV/analysis/native-table/slicer + Excel styles/sort/filter/freeze/insert-delete-autosum-clear-merge/names-protection-comments + Word ribbon 11 tab/45 nhóm/173 lệnh + **bảng: insert/delete row-column, header repeat, merge/split cells (gridSpan/vMerge)** + mail merge NEXT theo run/index/arrange/wpg/nested-table/exclusion/rich-split + cover/text-box/shapes/icons/chart/watermark/caption/theme/style-set/figures/protect + comment/track changes/markup/undo-find/nav-pane/hyperlink/symbol/online-video/spellcheck-grammar/insert-table-image/run-font/paragraph-list-style/page-border-color-reading/ruler/dark/header-footer/notes/citations/TOC/equation/ink/columns-accessibility/image + PPT slide ops/comments/SmartArt/media + PDF annotation/text-search, chạy bằng `npm run office:test`.
- `src/frontend/mobile/src/app/pages/office-viewer/`: Ionic page `/office/viewer` (read-only) import parser qua `@plugins/office-webapp/*`, mở local hoặc ERP `?docId=&version=` (metadata + content API), không copy parser.
- `web/scripts/generate-samples.mts`: sinh file mẫu (`sample-cf-dv.xlsx`, `sample-smartart.pptx` với SmartArt + media, `sample-layout.docx` cho cột/section/accessibility, `sample-review-image.docx` cho ảnh + markup) để QA thủ công; đặt `SAMPLE_MEDIA_DIR`/`SAMPLE_IMAGE_DIR` để nhúng mp4/wav/png thật (ffmpeg).
- `web/qa/mobile-harness.html`: harness iframe 390×844 / 844×390 để đo `scrollWidth`, touch target.
- Backend Quarkus: `plugin.json`, migration `V1.0.0`/`V1.0.1`/`V1.0.2`, API metadata + binary content + version + Share ACL; **14 JUnit tests** (13 khi MinIO tắt): unit + PostgreSQL thật (migrations + service CRUD/ACL qua JDBC) + MinIO thật (SigV4 put/get) + **E2E multipart** qua `PluginDataClient` gRPC contract tới PostgreSQL thật.

## Chạy

```bash
npm run office:test
npm run office:ui:build
npm run office:server:build
npm run office:server:test   # PostgreSQL tự dò localhost:5432, MinIO khi localhost:9000 sống
docker compose --profile storage up -d minio   # bật MinIO cho integration test
```

Integration test nhận env: `OFFICE_IT_DB_URL`, `OFFICE_IT_DB_USER`, `OFFICE_IT_DB_PASSWORD`,
`OFFICE_IT_MINIO_ENDPOINT`, `OFFICE_IT_MINIO_ACCESS_KEY`, `OFFICE_IT_MINIO_SECRET_KEY`.
Thiếu dịch vụ thì test tự skip, không fail bộ unit test.

Build xuất vào `plugins/office-webapp/src/main/resources/META-INF/resources`.

## Chưa có

**Word đạt 20/21 nhóm client (W-A21 một phần: tổng số trang khớp, bố cục từng trang chưa khớp — task-514) và ribbon theo Office 365 web: 11 tab, 45 nhóm, 173 lệnh gồm tab **Bảng** theo ngữ cảnh (chèn/xóa hàng cột, hàng tiêu đề lặp, chia đều cột, căn ô/bảng, **gộp ô / tách ô**), chữ gõ trong ô bảng vào model + `w:t`, **ô gộp `w:gridSpan`/`w:vMerge` vẽ `colspan`/`rowspan`**; chỉ còn Macros disabled (Word for the web không chạy VBA)**. Mailings mail merge CSV/XLSX, Index XE + số trang, Arrange floating `wp:anchor` (position/wrap/align/rotate/z-order/selection pane/group) hoạt động. Đã kiểm chứng trên **tài liệu thầu thực 1.2MB**: 30 part, 5 ảnh, 14 bảng XML (1 lồng), 50 hyperlink, TOC `w:sdt`, logo header; **phân trang thật 546 trang deterministic: trang 7 kết thúc đúng bảng dịch vụ, trang 8 đúng heading “Đề xuất giải pháp kỹ thuật”, trang 19–21 đúng mốc Word; trang 8–19 mean 0,992 (12/12 ≥0,8, 9 trang trùng Word 1,0), toàn tài liệu mean 0,582/98 trang ≥0,8 — khối bảng dài vẫn chưa khớp hoàn toàn (task-514/515/516); ngắt dòng `w:br` trong ô bảng render đúng (733 break/579 ô), **ô bảng vẽ theo `w:tcPr` như Office 365** (fill `w:shd`, `w:vAlign`, viền từng cạnh `w:tcBorders`, margin `w:tcMar`; kẻ mặc định đen)** (style metrics `styles.xml`, `w:tblGrid`, `w:pgMar`, line spacing 1.079×1.054), header/footer số trang động; **TOC tự cập nhật số trang** sau phân trang (không cần Update TOC); **nested table render đệ quy nhiều cấp**; **square/tight/through reflow thật, behind/front stacking z0/z3, topAndBottom đúng y (kể cả giữa hai đoạn), y độc lập anchor, exclusion plan nhiều float, line-level split cho cả đoạn có ảnh/textbox**.
